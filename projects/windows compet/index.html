Windows桌面打字&手柄识别工具，含三角符文各种角色皮肤

项目简介

Windows桌面打字&手柄识别工具，含三角符文各种角色皮肤 工具是x发布的compet的补丁包，支持手柄识别以及游戏时候的按键和手柄识别，理论上其他打字桌宠可通用（如果是py代码版本的）

使用说明

gamepad-package.exe解压后文件夹中数十个文件需要放置到和桌宠软件exe同目录下。使用的时候请首先按下gamepadsetting.bat来配置手柄按键，目前按键键位按照xbox手柄键位书写。而后按下start.vbs进行启动。

ggdw为swapspamton的皮肤包。addispam为ads时期spamton的皮肤包，dnt为defernull tenna的皮肤包，解压后即可使用，如软件支持zip导入，也可直接导入。

config.json中可以查看各个桌宠的按键配置规范，f18-f24和上下左右按键等为原本配置的手柄键位。

不支持开机自启，需要自启请自行将start.vbs添加到开机自启的注册表中。

下载

下载手柄按键补丁包 下载addispam皮肤包 下载swapspamton皮肤包 下载dfntn皮肤包 github release

使用提示

如果下载后无法打开， 或者打开后立即关闭， 请检查 Windows 安全中心和防火墙是否允许该软件运行。 大概率是被防火墙拦截。
