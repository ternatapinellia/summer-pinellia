OpenQQ Plugin

项目简介

本工具用于为开放平台机器人后台回调提供稳定的 Webhook 地址。 通过 Caddy 提供 HTTPS 反向代理， 配合 FRP 内网穿透， 解决本地服务器无法直接提供公网 HTTPS 回调地址的问题。

使用场景

适用于：

  • 没有公网 IP 的机器人服务器
  • 本地运行机器人程序，需要公网 Webhook 地址
  • 不希望购买国内备案域名的用户
  • 需要长期稳定回调地址的开放平台机器人

部署方式

方案 A：拥有国内域名

如果拥有已经备案的国内域名， 可以直接部署。 下载工具包后：

  1. 修改 Caddyfile
  2. 修改 config/bots 文件
  3. 填写机器人 AppID 和 Secret
  4. 启动服务即可

其中 bots 文件需要填写开放平台机器人的身份信息。 Caddyfile 用于配置 HTTPS 域名以及反向代理规则。

方案 B：没有国内域名

可以租用国外云服务器。 推荐：

  • 日本节点 VPS（延迟较低）
  • Linux 系统
  • 安装 Caddy + FRP

服务器端负责：

  • 绑定公网域名
  • 提供 HTTPS
  • 转发 Webhook 请求

本地服务器负责：

  • 运行机器人程序
  • 运行 frpc
  • 保持与 VPS 的连接

Linux 部署流程

1. 更新系统 

sudo apt update
sudo apt upgrade -y

2. 安装基础工具 

sudo apt install wget curl unzip nano -y

3. 安装 Caddy 

sudo apt install caddy -y

4. 编辑 Caddy 配置 

sudo nano /etc/caddy/Caddyfile
示例： 
your-domain.com {

    reverse_proxy 127.0.0.1:19093

}
保存： 
Ctrl + O
Enter
Ctrl + X
重载： 
sudo systemctl reload caddy

5. 安装 FRP

下载对应 Linux 架构版本： 
uname -a
解压： 
tar -zxvf frp.tar.gz
进入目录： 
cd frp
启动： 
./frpc -c frpc.ini
FRP 支持将内网服务通过公网服务器转发出去，常用于没有公网 IP 的场景。:contentReference[oaicite:2]{index=2}

配置文件修改

config/bots

修改： 

appid=你的机器人appid

secret=你的机器人secret
替换成开放平台提供的信息。

Caddyfile

修改域名： 

your-domain.com

修改代理端口： 

127.0.0.1:你的监听端口

frpc.ini

示例： 

[common]

server_addr = VPS地址

server_port = 7000


[openqq]

type = http

local_ip = 127.0.0.1

local_port = 你的机器人端口

custom_domains = your-domain.com

启动检查

查看 Caddy： 

systemctl status caddy

查看 FRP： 

ps aux | grep frpc
