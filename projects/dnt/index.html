DNT桌宠

项目简介

DNT桌宠是一款 Windows 桌面宠物程序。 支持桌面互动、语音、提醒、便签、新闻、外观切换等功能。

使用说明

左键点击桌宠可以进行互动和显示对话。 右键点击桌宠可以打开菜单以及退出程序。 控制面板、新闻界面、便签界面同样可以通过右键退出。

支持中英文切换。 如果不需要互动功能，可以暂停、隐藏桌宠， 或者关闭自动对话。 关闭自动对话后，会停止时间间隔对话以及点击桌宠触发的对话。

支持调节桌宠音量，也可以关闭声音。 固定时间会有喝水、吃饭、睡觉提醒。 支持 Windows 开机自启动。 右键菜单中的便签功能可以记录日常灵感或重要事件。

右键可以切换桌宠形态。 形态 2 拥有 7 套服装。 按住 Ctrl 并滚动鼠标滚轮，可以调整桌宠大小。

使用提示

下载 Release 压缩包后解压， 直接双击 desktoppet.exe 即可使用。

如果下载后无法打开， 或者打开后立即关闭， 请检查 Windows 安全中心和防火墙是否允许该软件运行。 大概率是被防火墙拦截。
