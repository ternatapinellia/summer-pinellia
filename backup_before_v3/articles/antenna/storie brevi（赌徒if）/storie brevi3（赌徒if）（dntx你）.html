你不明所以地被tenna拽到了T休息室，不知怎么的，你只觉得你自己是距离回家这个目标越来越远了——但你并不敢反驳他，他漆黑着屏幕，大抵心情又不是很好的样子。

只不过被拽到T休息室以后，你有点儿发蒙……你完全没想到，这个休息室虽然看着还挺宽敞的，但是大概是tenna的私人休息室，总之，虽然宽敞，而且井井有条，但是这中间只有一张床——难道是要你和他一起在这儿休息吗？你有点不太确定。

而tenna只是重新打开了屏幕，恢复了面无表情的样子，他并没有看向你，不知是不是为了掩饰自己的情绪，或者是害怕暴露出来一类的，他只是干巴巴地像是命令一般地说道：“好了，你今晚就睡在这儿吧。”

你眨巴眨巴眼睛，还是决定装作不懂的样子问道：“那你睡在哪儿？”

“我睡在这里。”他说着，用手指了指那张床，又一次关闭了屏幕。

你瞪大了眼睛，老天爷啊，今天不是才刚刚见到面吗，怎么下一秒钟就要同床共枕了？！这似乎不大对劲吧……但是tenna肉眼可见的，只是变成了小小的一只，甚至上不去床。你犹豫了一会儿还是把他抱到了床上，紧接着他自动缩到了角落里头，只是屏幕仍然关闭着，剩下的一大块区域看上去都是你的了。

此情此景，你也不好再问他什么问题了……他看上去太弱小，太脆弱了，和你印象当中那本书中曾经写过的形象完全不一样……如果不是确认他的名字，你都要以为自己进入了另一本书。但是……即使你的确是进入了那本书，你又该怎么办呢？如果你现在帮助了tenna，那会不会……取代了后续女主的那个位置？这样做到底是不是对的？如果……只是如果，你帮助了他，安抚了他，你真的能保证自己能够做到一切吗？你不知道，

但你最后还是跪坐在了床上，轻轻地抱住了这个tenna，你的手指在他的屏幕上摸了摸，是那种湿漉漉的泪水……你想了想，盘腿坐下，让他坐在了你的腿弯弯中，你轻轻地拍了拍他的脑袋，轻轻地哼着一模一样的歌谣，轻声地祝福他幸福和快乐。

而这个tenna只是无声地流淌着眼泪，不知道过了多久，他的屏幕又打开了，他的嘴角仍然下弯着，而他只是轻轻地扯了扯你的衣袖子：“所以……所以你会永远地看我的节目的，对吧？”他的声音是那样的急促，又是那样的苍白，你看着小小的tenna，不忍心说出真相，最后只是微微歪过头来说道。

“嗯，我希望你能够永远幸福快乐，我会留下来看你的节目的。”说着，你又是拍了拍他的脑袋，你感觉到心虚和内疚——你还在说着你觉得你并不一定会兑现的承诺，你还在欺骗他……明明这并不是你的本意，你只是希望他的心情能够好一些而已。

你听不到他的哭声了，而你也只是轻轻用手拍了拍他的背。你看着他漆黑的屏幕，确认他大概是真正地睡着了，才小心翼翼地把他放到了枕头上，盖好了被子，而你只是拿起了另一床被子躺在沙发上睡着了。

第二天一早，最先响起来的反倒是敲门的声音，你揉了揉眼睛过去打开房门，入眼的却是一个比你矮上一截子的麦克风头套——你愣了愣，对方大概也愣了愣，随后只是绕过你进了房间开始呼喊tenna：“老板，现在到你的起床时间了。”

紧接着，你看到床上缩成一团的那个小小的身形又一次变大，直到变成了他常规的体型——他仍然没有打开屏幕，只是用沙哑的声音应了一声：“嗯，mike。”

“老板，我注意到你的房间里面多了一个陌生的光之民，她可能会对你的事业产生影响……你知道的，按我们说得来，只有保持足够残酷和尖锐才能统领好手底下的员工，才能让更多的光之民留意你，不至于看低你，不至于让你受到伤害，毕竟除了mike以外没人关心你这台老电视了，对吗？所以我们应该把她赶走才对……”

你本来想要反驳这个喋喋不休的mike的话……因为他说的在你听来是完全错误的，为什么要那样做才能够吸引到其他人？但是他说要赶走你……或许能让你回到光世界？于是你没再开口了。

你只是冷静地坐在沙发上头望着tenna，他漆黑的屏幕正瞧着你——也许他正在看你，但是你不能确定，你只是听到了他冷淡的声音：“我知道，但是我需要光之民帮我评判节目的质量。”

“但是老板，你的节目表演给我们看，由我们来帮忙评价就够了……”那个mike仍然在说话，只是tenna打断了他的话。

“够了，我的节目还是需要光之民看的。所以……我要求留下这个光之民，并且，你们也必须善待这个光之民。”他的声音仍然硬邦邦的，只不过你在那种硬邦邦的声音之中察觉到了些许的差异——似乎，他还是不大习惯这么说话的。

但你看得出来，他如果不这样……就只会被这些员工蹬鼻子上脸，你不确定自己是否能忍心看得下去这种情况……紧接着tenna背过身去，下达了逐客令：“够了，总之你先出去。”

那个名为mike的家伙郁闷地走了出去，你也想跟在后头走出去，而tenna却转身喊住了你。

“那个，你留下来。”他的声音稍微温软了一点。

你愣愣地停下了脚步，最后只是转身重新坐在了沙发上。

Tenna看着你，欲言又止：“你，那个……”

也许他是想要问你的名字？总之你率先打断了他的话说道：“我是Y/N。”

“嗯，Y/N。刚刚的话你也听到了，你觉得怎么样？”tenna之前一直听着TV WORLD这些员工给他提的意见……当然，有一部分原因是他真的觉得自己需要变成这样，是他觉得自己足够冷酷，足够尖锐，才不至于再受到任何的伤害。而另一部分……是他听着那些员工的建议，努力在让自己变得更残酷，毕竟，听起来已经没有人在乎自己了——除了那些员工。

大概就还差那么几天的时间……总之tenna是这样感觉的，大概就只差几天，自己就会按照底下那些暗之民的说法，彻底变成他们所希望，自己也希望的那种形象。只不过，在剩下的几天当中他仍然有所动摇，在这种动摇时期结束以后，他就打算再也不去那处圣诞树下了。

……只是，他昨天看见了你，一个光之民。

你愣了愣，开始组织自己的语言：“嗯……那个，我觉得他说的话的确有点儿道理，你得变得了冷酷一点，至少……不要轻易显露出你的情绪？”你不确定你说的话是对是错，只知道他的屏幕关闭着，而他再度转过身去，无悲无喜一样地问道。

“所以，你觉得他说的是对的？”

你连忙摇摇头，而后注意到他正背对着自己，也不知道他是害怕看见你的表情，还是害怕被你看见他的表情，你只是急匆匆地说道：“当然不是。”

“那你觉得应该怎样呢？”他的声音仍然十分平淡，你还在思考到底该怎样回答他的问题，就见到tenna突然转过身来，而他的屏幕也亮了起来，是那种锃亮的感觉，还带着不断盘绕着的黑蓝色的圆圈，汇聚成了一个漩涡。

他的声音很平静，还带着点儿紧张：“这样呢，这样可以吗？只要这样做，就能让那些光之民都留下来了……”他只是在平铺直叙。

你觉得一阵晃神，在这一瞬间，你似乎听见了很多声音，有你的弟弟妹妹依恋着你的问询声，有你的父母慈祥地说着爱你的声音，有他们正说着以后会一直照顾你的声音——霎那间你明白了，这一切都是幻象，这根本是不可能发生的事情，这只是……你仍然还留有期待的事情而已。

所以你摇摇头，让自己从这个美好的幻梦中清醒，与此同时，你推开了tenna的电视脑袋。你的面颊苍白，额头上还滴落着冷汗，而tenna被你推开以后只是关闭了屏幕，他沉默着，似乎想要说些什么却最终没有说出口。

他只是垂着电视脑袋，掰着自己的手指头，似乎有些紧张，可他面上却什么表现都没有。

你长呼出一口气，连忙摇摇头：“不……不是这样的，你不能这样做。我不会喜欢的，其他发现真相的光之民也不会喜欢的。”你轻声吐露着这个事实。

“……喜欢？我不需要他们的喜欢，我只是希望，他们能够看着我，有越来越多的人看我罢了。”tenna的声音仍然十分平静，可你却从中捕捉到了些许平静的疯狂感……天哪，看来这个tenna的确比自己书中看到的那个更脆弱一点儿，可是同事，他却也显得更加疯狂了。

你不知道该怎么说才好，最后只是轻轻走上前两步拉住了tenna的手，轻声说道：“嗯……好。如果你只是想要别人一直看着你的话，这样做是不对的，至少你不能对我这样做，这样我只会远离你。”

Tenna闻言牵住了你的手，他的电视脑袋还是没有直视着你，他只是问道：“那么……你要怎样才会留下来？”他的声音紧绷着，你恐怕如果你提出离开，tenna也只会试图再次催眠你，让你觉得这里一切都是美好的，再也不想要离开。

你犹豫了一会儿，还是说出了谎言，你也不知道是为了安抚他的情绪，还是为了从tenna这儿得到更大的利益——比如，至少让你能够在这个世界自由探索一类的。

“只要你不这么对我，我会永远留下来的。”你轻声说着，说着你已知的谎言，你感到了愧疚，感到了心虚，你知道自己做不到，知道自己会违反这个承诺……但你还是选择了这么做。
