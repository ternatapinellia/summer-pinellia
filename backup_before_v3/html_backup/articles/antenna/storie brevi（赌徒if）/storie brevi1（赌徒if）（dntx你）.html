你合上了手中的这本书，若有所思，这是你近来翻阅完毕的一本小说……你本来是对爱情故事不怎么感兴趣的，毕竟你本人并不相信爱情，你不知道爱到底算是什么……这些小说都是你打发时间的读物而已，毕竟你才高考结束。

而之所以会看这本爱情小说，原因无他，是里头的女主角和你的名字一模一样——你好奇这个有着你的名字的女主角会有着怎样的未来，所以你看完了这本叫做《赌徒》的书籍。好吧，和其他的爱情小说差不多，无非是女主角和男主角最后过上了幸福圆满的生活的故事。你有些失望地合上了这本书，虽然这书中女主角的经历和你也是一模一样，虽然这是两个都不理解爱的人最终接纳了对方也接纳了爱情的故事，但是你并不喜欢这样的结局，你总是在想，如果是你的话，绝对会做出截然不同的事情。

抱着这样的信念，你上床睡着了。再睁开眼的时候你不是自然醒的，而是被吵醒的，你听见了pippins——虽然你不知道为什么下意识脑海中浮现出了这个名字，总之你下意识觉得他们是pippins，你听见了他们的声音：“快点，快点，tenna先生都起来好久了，你想要他发火吗？”

Tenna？你愣了愣，总不能是你穿越到了你读过的小说里头吧——此时你也在镜子里头看了看，自己还是自己，并没有变换容貌，喊着系统什么的也没有任何东西搭理你，看来要不是你做了个清醒梦，要不是你真的倒霉突然穿越了。

紧接着是另一个pippins的声音，他的声音还有点儿飘飘然：“哎呀，要是迟到了被tenna先生骂两句不也挺舒服的吗？”他的声音有些飘飘然，看上去这个pippins的确是很期待了。

你的嘴角抽了抽，反正这儿大概是个废弃的房间，倒还算是干净，不过并没有人来这儿看，你还能在这里躲一会儿，你这样想着的时候，又听到了zapper的声音：“安静，安静。Tenna先生让我们去集合了。”

顿时那些pippins都安静了下来，shadow guy吹响了代表喜悦意味的小曲，当然，很快也停了下来。你听着浩浩荡荡的脚步声逐渐远去，才稍稍松了口气。那本书上可没有写这些员工都是什么样子的……也没有写原本的TV WORLD是什么样子的，你只知道点儿关于tenna的信息。为了确认自己到底是不是误入到了那本书当中，你犹豫了一会儿，还是悄悄探头出这个房间，四处看了看，确认这边没有遗留下来任何一个暗之民以后，你才慢慢地朝着他们离开的方向走去，路途的终点似乎是一扇大门，你听到其中传来了窸窸窣窣的声音，于是你暂且不敢开门，只是看了下门上的标签，确认这儿大概是休息室，然后你听到了里头传来了那些暗之民喧闹嘈杂的声音，紧接着是tenna的声音——你确定你没有认错，毕竟那和书中的描写几乎是一模一样的，带着点儿刻意的沙哑和低沉。

你眨巴眨巴眼睛，偷偷地贴在大门上面继续偷听，房间里很安静，只剩下tenna的声音，他继续吩咐道：“然后下午三点的时候，是你们这些pippins负责主演，是游戏图版的部分，可不要搞砸了。”

紧接着是那些pippins欢欣雀跃地欢呼声，你看了看墙上挂着的钟表，现在是九点钟，也就是说，等会儿节目就要开始上演了。

你看得目瞪口呆——要你说，台下的这些夸赞大概都并不是真心实意的吧，只不过tenna还是带着夸赞，嘴角又一次下弯着，只是带领着台上的员工下去了，而舞台上的暗之民也陆陆续续地散场，离开了舞台的现场，一时之间，只有一种……黑暗和孤寂的感觉环绕着你。

……无论如何，你想，你的当务之急都是回到曾经的世界。虽然那个世界并不怎么美好，但你至少还有着点儿活下去的期望，在这儿你人生地不熟的，都不知道到底该去哪儿。

想着想着，你才发现你有点饿了……嗯，看上去你得想办法去这个地方的厨房一趟才行了。舞台上挂着钟表，你看了一眼，现在的时间是十一点半，于是你敲了敲有些麻了的双腿站了起来，重新打开大门回到了后台的区域，你往前走，听到休息室的房间中传来了声音，似乎是那对天气夫妇正在说些什么，你一时间不敢进去，却又不知道去哪个房间比较好，只能在他们推开休息室大门的时候龟缩在门后，祈祷着并没有人能看见你——嗯，不过，还当真没有人看见你，大概一般也没有人会注意门后吧。
